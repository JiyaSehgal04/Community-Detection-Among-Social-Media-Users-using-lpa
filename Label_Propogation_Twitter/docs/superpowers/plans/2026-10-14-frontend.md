# Frontend (7 screens) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the Vite + React + TypeScript web UI in `frontend/` for the existing FastAPI backend: Explorer, Run, Graph, Communities, Step-through, Compare and User lookup.

**Architecture:** A single-page app. API types are generated from the backend's OpenAPI schema, so a changed field breaks the build instead of the demo. The selected ego and the latest run live in the URL (`?ego=..&job=..`). A small `useApi` hook gives every screen loading, error and empty states; Cytoscape draws the graph; Recharts draws the Compare chart.

**Tech Stack:** Vite 8, React 19, TypeScript 5.9, React Router 7, Cytoscape 3, Recharts 3, openapi-typescript 7. Node 26 / npm 11 are installed.

**Spec:** `docs/superpowers/specs/2026-10-07-lpa-api-frontend-design.md` (sections 4-6 and 5 "Reliability"). The backend API it consumes already exists (`backend/app.py`, 8 endpoints, 91 tests passing).

**Verified before writing this plan:** the exact dependency set below was installed and built in a scratch project, and every file in this plan was typechecked (`tsc --noEmit`) and built (`vite build`) against types generated from the real API. The API's CORS preflight for `http://localhost:5173` was checked against the real app. The step-through off-by-one (`changed[i]` lines up with snapshot `i`, the first entry is 0) was found and fixed that way.

## Global Constraints

- Work only inside `frontend/` (and the docs in Task 8). The backend, pipeline, tests and `outputs/` are not modified.
- API base URL: `VITE_API_URL`, default `http://localhost:8000`. The API allows the origins `http://localhost:5173` and `http://127.0.0.1:5173`, so the dev server must run on port 5173.
- Exactly 7 screens at: `/explorer`, `/run`, `/graph`, `/communities`, `/steps`, `/compare`, `/users` (`/` redirects to `/explorer`).
- Graph colours: 12 distinct community colours, grey for every community beyond the 12 largest, and the legend says "other".
- `circle_f1` is `null` for egos without circles and must display as "n/a", never 0. Circle F1 is always shown next to the one-community baseline.
- `direction` defaults to `mutual` on the Run form (the EDA found `any` collapses into one giant community). The API's `warnings` are shown to the user.
- Every screen has loading, error and empty states; a crash in a screen is caught by an error boundary; an "API unreachable" banner appears when the API stops answering.
- No frontend unit tests (agreed): the guards are generated types, `npm run typecheck`, `npm run build`, and the manual checklist in Task 8.
- No git commits unless the user asks (their standing rule). Each task ends with a checkpoint instead.
- Dependencies are exactly those in `frontend/package.json` below. `typescript` stays on `^5.9.3` because `openapi-typescript` 7 requires TypeScript 5.

## Deviations from the spec (decided while planning)

1. **No "tuned preset" on the Run screen.** The tuned configuration uses three outlier rules (`token_max_share`, `hub_cap`, `max_tokens`) that `POST /api/detect` does not accept. A preset with only the graph settings would not reproduce the tuned result and would be misleading. Adding it needs a backend change and is out of scope here.
2. **Compare shows what `/api/compare` serves**: the saved top-20 experiment summaries (3 graph modes x 3 algorithms, both follow directions). The held-out final evaluation (`outputs/final/`) has no endpoint yet, so it is not shown.

## Review Focus

Each line is pinned by a step in Task 8's manual checklist (the frontend has no unit tests by agreement), and most also by a code path named below.

1. **API down** (server stopped or wrong port): a red banner appears within about 10 seconds and each screen shows "The API is not reachable" with the start command, never a blank page. (`ApiBanner`, `ErrorBox`)
2. **Expired or unknown run** (restart the server, or use a made-up `job` in the URL): Graph, Communities, Step-through and User lookup show "Not found ... Run the detection again" with a link, not a crash. (`ErrorBox` for 404)
3. **Ego without circles**: Circle F1 shows "n/a - this ego has no circles", not 0.000. (`MetricCards`)
4. **Edgeless or all-singleton result**: Graph and Step-through still render the users (grid layout) and a run with only one snapshot disables Play. (`GraphView`, `Player`)
5. **More than 12 communities**: the extra communities are grey and the legend shows "other (n)"; Communities hides one-user communities behind a checkbox. (`rankColors`, `Legend`, `Cards`)

```ts
import type { components } from "./schema";
import type { DetectRequest, DetectResponse, GraphResponse, TraceResponse, UserResponse } from "./types";

export const API_URL: string = import.meta.env.VITE_API_URL ?? "http://localhost:8000";

/** Any failed call. status 0 means the API could not be reached at all. */
export class ApiError extends Error {
  constructor(public status: number, public kind: string, public detail: unknown) {
    super(typeof detail === "string" ? detail : JSON.stringify(detail));
  }
}

async function request<T>(path: string, init?: RequestInit): Promise<T> {
  let res: Response;
  try {
    res = await fetch(API_URL + path, init);
  } catch {
    throw new ApiError(0, "unreachable", `Cannot reach the API at ${API_URL}. Is it running?`);
  }
  if (!res.ok) {
    const body = await res.json().catch(() => null);
    throw new ApiError(res.status, body?.error ?? "error", body?.detail ?? res.statusText);
  }
  return (await res.json()) as T;
}

const userCache = new Map<string, UserResponse>();

export const api = {
  egos: () => request<components["schemas"]["EgosResponse"]>("/api/egos"),
  stats: () => request<components["schemas"]["StatsResponse"]>("/api/stats"),
  detect: (body: DetectRequest) =>
    request<DetectResponse>("/api/detect", {
      method: "POST",
      headers: { "Content-Type": "application/json" },
      body: JSON.stringify(body),
    }),
  graph: (job: string) => request<GraphResponse>(`/api/graph/${job}`),
  communities: (job: string) => request<components["schemas"]["CommunitiesResponse"]>(`/api/communities/${job}`),
  trace: (job: string) => request<TraceResponse>(`/api/trace/${job}`),
  compare: () => request<components["schemas"]["CompareResponse"]>("/api/compare"),
  user: (id: number, job?: string | null) =>
    request<UserResponse>(`/api/users/${id}` + (job ? `?job_id=${job}` : "")),
  /** Same as user(), remembered for the session (used by graph hover). */
  async userCached(id: number, job?: string | null): Promise<UserResponse> {
    const key = `${id}:${job ?? ""}`;
    const hit = userCache.get(key);
    if (hit) return hit;
    const fresh = await api.user(id, job);
    userCache.set(key, fresh);
    return fresh;
  },
  /** True when the API answers at all (used by the "API unreachable" banner). */
  async ping(): Promise<boolean> {
    try {
      await fetch(API_URL + "/openapi.json");
      return true;
    } catch {
      return false;
    }
  },
};
```

- [ ] **Create `frontend/src/api/useApi.ts`:**

```ts
import { useEffect, useState } from "react";
import { ApiError } from "./client";

export interface ApiResult<T> {
  data: T | null;
  error: ApiError | null;
  loading: boolean;
  reload: () => void;
}

/** Run `load` whenever `deps` change; tracks loading and error state. */
export function useApi<T>(load: () => Promise<T>, deps: unknown[]): ApiResult<T> {
  const [state, setState] = useState<{ data: T | null; error: ApiError | null; loading: boolean }>({
    data: null,
    error: null,
    loading: true,
  });
  const [tick, setTick] = useState(0);

  useEffect(() => {
    let alive = true;
    setState((s) => ({ ...s, loading: true, error: null }));
    load().then(
      (data) => alive && setState({ data, error: null, loading: false }),
      (e) =>
        alive &&
        setState({ data: null, error: e instanceof ApiError ? e : new ApiError(0, "unknown", String(e)), loading: false }),
    );
    return () => {
      alive = false;
    };
  }, [...deps, tick]); // eslint-disable-line react-hooks/exhaustive-deps

  return { ...state, reload: () => setTick((t) => t + 1) };
}
```

```ts
import { useSearchParams } from "react-router-dom";

/** The chosen ego and the latest run live in the URL (?ego=..&job=..), so a refresh or a shared link keeps them. */
export function useSelection() {
  const [params, setParams] = useSearchParams();
  const rawEgo = Number(params.get("ego"));
  const ego = params.get("ego") && Number.isFinite(rawEgo) ? rawEgo : null;
  const job = params.get("job");

  function update(next: { ego?: number | null; job?: string | null }) {
    const p = new URLSearchParams(params);
    for (const [key, value] of Object.entries(next)) {
      if (value === null || value === undefined) p.delete(key);
      else p.set(key, String(value));
    }
    setParams(p);
  }
  return { ego, job, update };
}
```

```ts
/** 12 distinct community colours; every community beyond the 12 largest is drawn in grey ("other"). */
export const PALETTE = [
  "#2a78d6", "#eb6834", "#1baf7a", "#8e5bd6", "#d6a62a", "#d64a8e",
  "#2aa7c9", "#7a8a2a", "#c94a2a", "#5b6bd6", "#2ac98a", "#a0522d",
];
export const OTHER = "#b8b7ad";

/** Colour for each id, given how big each id is: the 12 biggest get palette colours, the rest grey. */
export function rankColors(sizes: Map<number, number>): Map<number, string> {
  const ranked = [...sizes.entries()].sort((a, b) => b[1] - a[1] || a[0] - b[0]);
  const colours = new Map<number, string>();
  ranked.forEach(([id], i) => colours.set(id, i < PALETTE.length ? PALETTE[i] : OTHER));
  return colours;
}

export function countBy(values: number[]): Map<number, number> {
  const counts = new Map<number, number>();
  for (const v of values) counts.set(v, (counts.get(v) ?? 0) + 1);
  return counts;
}
```

```tsx
/** Renders loading and error states for an API call, then the content. */
export function Query<T>({ result, children }: { result: ApiResult<T>; children: (data: T) => ReactNode }) {
  if (result.error) return <ErrorBox error={result.error} onRetry={result.reload} />;
  if (result.loading || !result.data) return <p className="muted">Loading…</p>;
  return <>{children(result.data)}</>;
}
```

```tsx
import { Component, type ReactNode } from "react";

/** Last line of defence: a crash in one screen shows a message instead of a blank page. */
export class ErrorBoundary extends Component<{ children: ReactNode }, { error: Error | null }> {
  state = { error: null as Error | null };
  static getDerivedStateFromError(error: Error) {
    return { error };
  }
  render() {
    if (this.state.error) {
      return (
        <div className="box error" role="alert">
          <strong>This screen crashed</strong>
          <p>{this.state.error.message}</p>
          <button onClick={() => this.setState({ error: null })}>Try again</button>
        </div>
      );
    }
    return this.props.children;
  }
}
```

```tsx
import { useMemo, useState } from "react";
import { useNavigate } from "react-router-dom";
import { api } from "../api/client";
import type { EgoRow } from "../api/types";
import { useApi } from "../api/useApi";
import { Query } from "../components/Status";
import { int, num, pct } from "../lib/format";
import { useSelection } from "../lib/selection";

const STAT_CARDS: [key: string, label: string, kind: "int" | "pct"][] = [
  ["users", "Users", "int"],
  ["follow_edges", "Follow edges", "int"],
  ["egos", "Ego networks", "int"],
  ["n_circles", "Circles", "int"],
  ["reciprocity", "Follows that are mutual", "pct"],
  ["share_with_hashtag", "Users with a hashtag", "pct"],
  ["share_with_mention", "Users with a mention", "pct"],
  ["share_with_no_tokens", "Users with no tokens", "pct"],
];

type SortKey = "ego_id" | "n_nodes" | "n_edges" | "density" | "n_circles";
const COLUMNS: [SortKey, string][] = [
  ["ego_id", "Ego"],
  ["n_nodes", "Users"],
  ["n_edges", "Follows"],
  ["density", "Density"],
  ["n_circles", "Circles"],
];
const PAGE = 100;

function EgoTable({ egos }: { egos: EgoRow[] }) {
  const navigate = useNavigate();
  const { ego: selected } = useSelection();
  const [sortKey, setSortKey] = useState<SortKey>("n_nodes");
  const [desc, setDesc] = useState(true);
  const [onlyCircles, setOnlyCircles] = useState(false);
  const [limit, setLimit] = useState(PAGE);

  const rows = useMemo(() => {
    const filtered = onlyCircles ? egos.filter((e) => e.has_circles) : egos;
    return [...filtered].sort((a, b) => (desc ? b[sortKey] - a[sortKey] : a[sortKey] - b[sortKey]));
  }, [egos, sortKey, desc, onlyCircles]);

  function sortBy(key: SortKey) {
    if (key === sortKey) setDesc(!desc);
    else {
      setSortKey(key);
      setDesc(true);
    }
  }

  return (
    <>
      <label className="small">
        <input type="checkbox" checked={onlyCircles} onChange={(e) => setOnlyCircles(e.target.checked)} /> only egos with circles
      </label>
      <table>
        <thead>
          <tr>
            {COLUMNS.map(([key, label]) => (
              <th key={key} onClick={() => sortBy(key)} className="sortable">
                {label} {key === sortKey ? (desc ? "▼" : "▲") : ""}
              </th>
            ))}
          </tr>
        </thead>
        <tbody>
          {rows.slice(0, limit).map((e) => (
            <tr
              key={e.ego_id}
              className={e.ego_id === selected ? "selected" : ""}
              onClick={() => navigate({ pathname: "/run", search: `?ego=${e.ego_id}` })}
              title="Click to run community detection on this ego"
            >
              <td>{e.ego_id}</td>
              <td>{int(e.n_nodes)}</td>
              <td>{int(e.n_edges)}</td>
              <td>{num(e.density)}</td>
              <td>{e.has_circles ? e.n_circles : "none"}</td>
            </tr>
          ))}
        </tbody>
      </table>
      {limit < rows.length && <button onClick={() => setLimit(limit + PAGE)}>Show more ({rows.length - limit} left)</button>}
    </>
  );
}

export function Explorer() {
  const stats = useApi(api.stats, []);
  const egos = useApi(api.egos, []);
  return (
    <>
      <h2>Dataset explorer</h2>
      <Query result={stats}>
        {({ stats: s }) => (
          <div className="cards">

              const v = typeof s[key] === "number" ? (s[key] as number) : null;
              return (
                <div className="card" key={key}>
                  <div className="muted small">{label}</div>
                  <div className="big">{kind === "pct" ? pct(v) : int(v)}</div>
                </div>

          </div>

      </Query>
      <h3>Ego networks</h3>
      <p className="muted small">Click an ego to run community detection on it.</p>
      <Query result={egos}>{({ egos: rows }) => <EgoTable egos={rows} />}</Query>
    </>
  );
}
```

```tsx
import cytoscape, { type Core } from "cytoscape";
import { useEffect, useRef } from "react";

interface Props {
  nodes: { id: number; degree: number }[];
  edges: { source: number; target: number }[];
  /** Colour for a node id; changing it recolours in place without redrawing the layout. */
  colorOf: (id: number) => string;
  onHover?: (id: number | null) => void;
  height?: number;
}

export function GraphView({ nodes, edges, colorOf, onHover, height = 560 }: Props) {
  const host = useRef<HTMLDivElement>(null);
  const cy = useRef<Core | null>(null);
  const colorRef = useRef(colorOf);
  const hoverRef = useRef(onHover);
  colorRef.current = colorOf;
  hoverRef.current = onHover;

  // Build the graph (and its layout) only when the nodes or edges change.
  useEffect(() => {
    if (!host.current) return;
    const instance = cytoscape({
      container: host.current,
      elements: [
        ...nodes.map((n) => ({
          data: { id: String(n.id), size: 6 + 2 * Math.sqrt(n.degree), color: colorRef.current(n.id) },
        })),
        ...edges.map((e, i) => ({ data: { id: `e${i}`, source: String(e.source), target: String(e.target) } })),
      ],
      style: [
        { selector: "node", style: { "background-color": "data(color)", width: "data(size)", height: "data(size)" } },
        { selector: "edge", style: { width: 0.6, "line-color": "#c9c8bf", opacity: 0.55 } },
      ],
      layout: { name: edges.length ? "cose" : "grid", animate: false, randomize: true } as cytoscape.LayoutOptions,
      minZoom: 0.2,
      maxZoom: 4,
    });
    instance.on("mouseover", "node", (ev) => hoverRef.current?.(Number(ev.target.id())));
    instance.on("mouseout", "node", () => hoverRef.current?.(null));
    cy.current = instance;
    return () => {
      instance.destroy();
      cy.current = null;
    };
  }, [nodes, edges]);

  // Recolour in place whenever the colouring changes (community view, or a step of the animation).
  useEffect(() => {
    cy.current?.nodes().forEach((n) => {
      n.data("color", colorOf(Number(n.id())));
    });
  }, [colorOf, nodes, edges]);

  return <div ref={host} className="graph" style={{ height }} aria-label="Network graph" />;
}
```

```tsx
function GraphBody({ graph, job }: { graph: GraphResponse; job: string }) {
```

```tsx
import { useCallback, useEffect, useMemo, useState } from "react";
import { api } from "../api/client";
import type { GraphResponse, TraceResponse } from "../api/types";
import { useApi } from "../api/useApi";
import { GraphView } from "../components/GraphView";
import { NeedJob, Query } from "../components/Status";
import { OTHER, countBy, rankColors } from "../lib/colors";
import { int } from "../lib/format";
import { useSelection } from "../lib/selection";

function Player({ graph, trace }: { graph: GraphResponse; trace: TraceResponse }) {
  const last = trace.snapshots.length - 1;
  const [step, setStep] = useState(0);
  const [playing, setPlaying] = useState(false);

  const index = useMemo(() => new Map(trace.nodes.map((id, i) => [id, i])), [trace]);
  // Colour a label by its rank in the FINAL partition, so colours stay put while the animation runs.
  const labelColours = useMemo(() => rankColors(countBy(trace.snapshots[last] ?? [])), [trace, last]);
  const colorOf = useCallback(
    (id: number) => {
      const i = index.get(id);
      return i === undefined ? OTHER : (labelColours.get(trace.snapshots[step][i]) ?? OTHER);
    },
    [index, labelColours, trace, step],
  );

  useEffect(() => {
    if (!playing) return;
    const timer = setInterval(() => {
      setStep((s) => {
        if (s >= last) {
          setPlaying(false);
          return s;
        }
        return s + 1;
      });
    }, 700);
    return () => clearInterval(timer);
  }, [playing, last]);

  function togglePlay() {
    if (!playing && step >= last) setStep(0);
    setPlaying(!playing);
  }

  const labels = new Set(trace.snapshots[step]).size;
  return (
    <>
      <div className="controls">
        <button onClick={togglePlay} disabled={last === 0}>{playing ? "Pause" : step >= last && last > 0 ? "Replay" : "Play"}</button>
        <input
          type="range" min={0} max={last} value={step} disabled={last === 0}
          onChange={(e) => { setPlaying(false); setStep(Number(e.target.value)); }}
          aria-label="Iteration"
        />
        <span>Iteration {step} of {last}</span>
      </div>
      <p className="muted small">
        {step === 0 ? "Start: every user has their own label." : `${int(trace.changed[step] ?? 0)} users changed label.`}{" "}
        {int(labels)} distinct labels now. Coloured users hold a label that survives to the end; grey users hold one that does not (or a small community).
      </p>
      <GraphView nodes={graph.nodes} edges={graph.edges} colorOf={colorOf} />
    </>
  );
}

export function StepThroughPage() {
  const { job } = useSelection();
  if (!job) return <NeedJob />;
  return <StepScreen job={job} />;
}

function StepScreen({ job }: { job: string }) {
  const graph = useApi(() => api.graph(job), [job]);
  const trace = useApi(() => api.trace(job), [job]);
  return (
    <>
      <h2>Step-through</h2>
      <Query result={graph}>{(g) => <Query result={trace}>{(t) => <Player graph={g} trace={t} />}</Query>}</Query>
    </>
  );
}
```
